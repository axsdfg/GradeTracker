GradeTracker_v1.3.apk  ·  com.gradetracker.app  ·  v1.3 (3)
判定：低风险离线工具 无网络权限 无第三方 SDK 调试签名 / debuggable

一句话结论

低风险等级

这是一个 纯本地离线的学生成绩记录工具：单个 WebView 外壳 + 一个 67 KB 的 HTML 单页应用 + ECharts 图表库，数据只写在本机 localStorage 里。

未发现任何恶意行为：没有 INTERNET 权限（物理上无法联网回传）、没有原生库、没有 JS 桥、没有广告/统计/推送 SDK、代码未混淆无加密载荷。

它的问题集中在「工程规范」而不是「恶意」：用 Android 默认调试证书签名、debuggable=true、allowBackup=true，属于典型的自建/内测包，不适合上架，也不适合把重要数据长期寄存在里面（导出功能大概率失效）。

为什么这很重要：调试证书是公开可预测的（每台机器的 debug.keystore 各自生成，但无身份背书）。用它签的包无法上架应用商店；日后换成正式签名，用户必须卸载重装（数据会丢）；任何人拿到同一个 keystore 都能签发「看起来是同款升级」的包。

4. 原生层实现：一个极简 WebView 外壳

反汇编 classes3.dex 后，MainActivity 的全部逻辑只有 4 个方法：

// MainActivity.java（根据字节码还原）
onCreate(Bundle b) {
    super.onCreate(b);
    WebView wv = new WebView(this);
    setContentView(wv);
    WebSettings s = wv.getSettings();
    s.setJavaScriptEnabled(true);
    s.setDomStorageEnabled(true);        // localStorage 依赖
    s.setDatabaseEnabled(true);
    s.setLoadWithOverviewMode(true);
    s.setUseWideViewPort(true);
    s.setAllowFileAccess(true);          // 读取 assets
    s.setAllowContentAccess(true);
    s.setBuiltInZoomControls(false);
    s.setDisplayZoomControls(false);
    s.setCacheMode(-1);                  // LOAD_DEFAULT
    s.setMixedContentMode(0);            // ALWAYS_ALLOW（冗余的宽松配置）
    wv.setWebViewClient(new MainActivity.1());
    wv.setWebChromeClient(new WebChromeClient());   // 空实现
    wv.loadUrl("file:///android_asset/index.html");
}

onBackPressed() { webView.canGoBack() ? webView.goBack() : super.onBackPressed(); }
onDestroy()   { webView.destroy(); super.onDestroy(); }

// MainActivity$1 extends WebViewClient
shouldOverrideUrlLoading(wv, url) { wv.loadUrl(url); return true; }
  • 安全 没有 addJavascriptInterface——网页与原生之间没有任何桥，JS 无法调用系统能力。
  • 安全 页面只从 file:///android_asset/ 加载，不加载任何远程地址；即便页面里写死了一个 URL 也打不开（无网络权限）。
  • 缺陷 未设置 DownloadListener，未重写 onShowFileChooser ⇒ 页面里的「导出数据 / 导入数据」在真机上大概率点了没反应（见第 6 节）。
  • 体验 返回键逻辑几乎恒走 super（单页应用没有历史栈），在「成绩详情」页按返回会直接退出应用而不是回上一屏。

5. 应用到底做了什么（前端功能与数据模型）

三个视图、零网络请求：

视图能力
概览总分、班级排名、年级排名（对比上一次考试显示「↑进步 N 名 / ↓退步 N 名 / —持平」）；分数趋势折线图（可切换科目/总分，含目标分标线、渐变面积）；科目雷达图（理科组合 / 文科组合 / 全科三套模板），得分率分级
成绩考试列表（按日期倒序）、详情弹层、编辑、删除；新增考试弹层含滚轮日期选择器、自定义下拉框
设置9 科满分与目标分配置、导出 JSON、导入 JSON、清空全部数据

内置数据模型

  • 科目（9 科，默认满分）：语文/数学/英语 150；物理/化学/生物/政治/历史/地理 100（典型新高考 3+3 组合）
  • 考试类型：月考、期中、期末、模拟考、其他
  • 每次考试：名称、日期、类型、总分、班排、年排；每科分数 / 满分 / 班排 / 年排
  • 存储：localStorage["grade_tracker_data"]，单个 JSON（subjects + exams），明文保存于应用私有目录 /data/data/com.gradetracker.app/app_webview/Local Storage
  • 代码质量：无 minify、无混淆、无 eval、无 fetch/XHR、无 cookie、无 postMessage、无动态脚本注入 —— 全部逻辑可读可审
隐私判断：成绩与排名属于未成年人个人信息，但本应用没有任何联网能力，数据不出设备。这是比任何「隐私承诺」都硬的保证——不是「承诺不上传」，而是「上传不了」。

6. 风险与缺陷清单

问题级别说明建议
debuggable=true中 调试构建产物。开启 USB 调试的电脑可用 adb shell run-as 读取应用私有数据，WebView 也可通过 chrome://inspect 直接调试页面 改用 release 构建（debuggable false）
allowBackup=true中 成绩数据可被 adb backup（Android 11 及以下）或系统云备份整体导出，且内容明文 设 android:allowBackup="false"，或配置 backup rules 排除 WebView 目录
默认调试证书签名中 无身份背书、不可上架、换签名需卸载重装、无法校验来源 生成正式 keystore，启用 v2+v3 签名
数据明文存储中低 成绩/排名以明文 JSON 存在本地。设备被 root 或备份被拷走即全部泄露 如需对外分发：加密存储或至少关闭备份
导出 / 导入大概率失效功能 导出用 Blob + <a download>，WebView 未注册 DownloadListener 时不会触发下载；导入依赖 <input type=file>，WebChromeClient 为空实现、未重写 onShowFileChooser，文件选择器通常不会弹出 补 DownloadListener + onShowFileChooser，或改为系统分享 / SAF
宽松的 WebView 配置低 setMixedContentMode(ALWAYS_ALLOW)、allowFileAccess/ContentAccess(true)。因无网络权限且页面全部本地，实际不可被利用，属冗余配置 收紧为 NEVER_ALLOW，按需开 fileAccess
innerHTML 拼接用户输入低 考试名称等输入直接进模板字符串再 innerHTML。手动输入只造成「自己 XSS 自己」；但若导入他人伪造的 JSON（考试名里带 <img onerror=…>），脚本会在 file:// 上下文执行——由于没有 JS 桥，最坏结果是页面被改坏，拿不到系统权限 导入时校验/转义字段，渲染改用 textContent
返回键直接退出体验 单页应用无路由栈，canGoBack() 恒为 false，在子页面按返回会退出应用 用 JS 桥或 OnBackPressedDispatcher 让页面先响应返回
无隐私政策 / 关于页合规 设置页只有科目配置和数据管理 若要分发，补齐隐私说明与版本信息

7. 建议

如果你打算自己用

  • 可以装、可以放心用：静态层面没有任何恶意或后门特征，也没有联网能力。
  • 不要把它当作唯一的成绩档案：导出功能很可能点了没反应，一旦卸载或清除数据，记录就没了。建议同时把原始成绩留一份在自己的表格/备忘录里。
  • 手机保持「USB 调试」关闭状态，可抵消 debuggable=true 的绝大部分影响。
  • 来源不明的第三方渠道转发的同款安装包要重新校验 SHA-256（本报告已给出），因为调试证书无法证明来源。

如果你是开发者（想正式发布）

  • release 签名 + 关闭 debuggable + 关闭 allowBackup，签名升级到 v2/v3。
  • 补齐 WebView 的下载与文件选择回调，让「导出/导入」真正可用——这是这类离线工具唯一的数据保险。
  • 导入 JSON 前做字段白名单校验，渲染时对用户输入转义。
  • 把 setMixedContentMode 改为 MIXED_CONTENT_NEVER_ALLOW，allowFileAccess 仅保留必要项。
  • 上架前补隐私政策页；应用名称含「成绩」且面向学生，注意教育类应用的内容合规要求。
