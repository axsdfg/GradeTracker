## 二、考试记录

| 功能 | 状态 | 实现要点 |
|---|---|---|
| 新增 / 编辑 / 删除 | ✅ | 弹层表单；单科分数与排名动态生成输入行 |
| 自动算总分 | ✅ | 保存时按当前计分模式现算，不做持久化冗余 |
| 考试详情 | ✅ | 各科分数、得分率、单科排名、与班级均分对比（有均分数据时） |
| 按学期过滤 | ✅ | 顶部学期胶囊；未归属的旧数据自动落到当前学期 |
| 表格粘贴导入 | ✅ | TSV/CSV，同日同名合并成一场考试；字段缺失走默认值 |
| 文件导入 | ⚠️ | 浏览器/`file://` 下 `<input type=file>` 可用；WebView 内需要原生 `onShowFileChooser`，未实现时页面提示改用粘贴导入 |

导入格式：

```csv
日期,考试名称,科目,分数,满分,班排,年排
2026-09-28,第一次月考,数学,134,150,5,31
```

`满分 / 班排 / 年排` 可省略；`日期` 支持 `YYYY-MM-DD`、`YYYY/M/D`。

## 三、分析

### 趋势

- 指标切换：总分 / 单科；
- 折线含满分参考虚线；
- 排名双折线（班排 + 年排），**纵轴反向**——越靠上名次越好，符合直觉；
- 逐次变化列表：每次考试相对上一次的 ± 值。

### 强弱

- 横向条形图：各科得分率 vs 个人均值；
- Z-score 排序：`(本次得分率 − 个人均值) / 标准差`；
- 提分优先级：按 `1 − 平均得分率`（到满分的空间）排序；
- 能力雷达：本次 vs 个人均值。

### 位次（一分一段）

- 分数 → 位次、同分人数、位次区间、超越考生百分比；
- 省控线对比：选批次线后显示高/低于线多少分，达标用颜色区分；
- 750 折算：用最近一次得分率折算到 750 分制；
- 三条更新路径：

| 路径 | 说明 | 前置条件 |
|---|---|---|
| 在线自动更新 | 设置页填 JSON 地址，开启「每 24 小时检查」 | APK 需 `INTERNET` 权限，且服务器允许 CORS |
| 本地导入 | 选 JSON/CSV 文件（考试院导出的表格可直接用） | 浏览器的文件选择，或原生 `onShowFileChooser` |
| 粘贴解析 | 从考试院网页/Excel 复制 `分数, 本段人数, 累计人数` 直接解析 | 无 |

- 示例数据：一键载入合成数据体验流程，界面与结果**强制标注**「示例数据 · 不可用于真实填报」。

> 原包没有 `INTERNET` 权限，所以「立即拉取」会失败并提示「可能未授予 INTERNET 权限，请改用导入」——这是**预期行为**。重新打包时默认会加上该权限（`tools/apk_repack.py`），加 `--no-net` 可回到零权限。

## 六、原生能力对照表

前端已按「桥不在就降级」写好，所以没做这些改造也不会崩：

| 能力 | 前端接口 | 降级表现 |
|---|---|---|
| 保存图片到相册 | `AndroidBridge.saveImage` | `<a download>` / 长按保存提示 |
| 导出文件到下载目录 | `AndroidBridge.saveFile` | 弹出可全选复制的文本框 |
| 系统通知 | `AndroidBridge.notify` | 首页页内提醒条 |
| 快照落盘 | `AndroidBridge.writeBackup` | 只写 localStorage |
| 文件选择 | `WebChromeClient.onShowFileChooser` | 粘贴导入 |
| 返回键 | `appHandleBack()` | 系统默认直接退出 |
| 桌面小组件 | — | ❌ 未实现（Glance / AppWidget） |

实现参考见 [`android/MainActivity.java`](../android/MainActivity.java)。
